### 竞赛打印版
#### 1. 赛场策略
##### 做题节奏
- 开场先快速扫题，找签到题和中档题。
- 一题卡 20 到 30 分钟还没有明确做法，先换题。
- 优先拿稳分，不要一开始就在第一题耗太久。
- 每过一题都回头看一眼边界和输出格式再交。

##### 读题顺序
- 先看数据范围。
- 再看输入输出格式。
- 再看是否多组数据。
- 再看下标从 `0` 还是 `1` 开始。
- 再看样例在提示什么性质。

##### 卡题自救
- 先分清卡在思路、证明、实现还是复杂度。
- 先写暴力，确认题意和性质，再考虑优化。
- 多手推小样例，优先看 `n=1`、全相同、全负数、无解。
- 做法太复杂时，优先怀疑方向错了。

##### 提交前检查
- 是否清空了上组数据。
- 是否漏了特判。
- 是否越界。
- 是否 `int` 爆了，需要 `long long`。
- 是否有除零、负取模、空容器访问问题。
- 输出格式是否严格符合题意。

#### 5. STL 高频函数
##### 排序
```cpp
sort(a.begin(), a.end());
sort(a.begin(), a.end(), greater<int>());
```
如果不用 `greater<int>()`，也可以自己写比较函数：
```cpp
bool cmp(int a, int b) {
    return a > b; // 降序
}
sort(a.begin(), a.end(), cmp);
```
##### 自定义排序
```cpp
bool cmp(const pair<int, int>& a, const pair<int, int>& b) {
    return a.second < b.second;
}
sort(v.begin(), v.end(), cmp);
```
规则：
- `sort` 的比较函数返回 `true`，表示 `a` 应该排在 `b` 前面。
- 想升序就写 `a < b`，想降序就写 `a > b`。
- 比较函数参数尽量写成 `const T&`，避免拷贝。
也可以用 `lambda`：
```cpp
sort(v.begin(), v.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
    return a.second < b.second;
});
```
##### `priority_queue` 自定义比较器
`priority_queue<int, vector<int>, greater<int>>` 里的 `greater<int>` 也可以换成你自己写的比较器。
写法一：结构体
```cpp
struct Cmp {
    bool operator()(int a, int b) const {
        return a > b; // 小根堆
    }
};
priority_queue<int, vector<int>, Cmp> pq;
```
写法二：比较 `pair`
```cpp
struct CmpPair {
    bool operator()(const pair<int, int>& a, const pair<int, int>& b) const {
        return a.second > b.second; // second 小的优先
    }
};
priority_queue<pair<int, int>, vector<pair<int, int>>, CmpPair> pq;
```
注意：
- `sort` 和 `priority_queue` 的比较器理解方式容易反。
- 对 `sort` 来说，返回 `true` 表示 `a` 排在前面。
- 对 `priority_queue` 来说，比较器决定“谁优先级更低”，默认写法更容易写反，建议直接记模板。

#### 6. 数学与位运算
##### `gcd`
```cpp
int gcd(int a, int b) {
    while (b) {
        int t = b;
        b = a % b;
        a = t;
    }
    return a;
}
```
或直接用：
```cpp
std::gcd(a, b);
```
##### `exgcd`
```cpp
int exgcd(int a, int b, int &x, int &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x);
    y -= (a / b) * x;
    return d;
}
```
##### 快速幂
```cpp
long long qpow(long long a, long long b, long long mod) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
```
##### 快速乘
```cpp
long long qmul(long long a, long long b, long long mod) {
    long long res = 0;
    while (b) {
        if (b & 1) res = (res + a) % mod;
        a = (a + a) % mod;
        b >>= 1;
    }
    return res;
}
```

#### 7. 前缀和、差分、双指针
##### 前缀和
```cpp
vector<long long> sum(n + 1, 0);
for (int i = 1; i <= n; i++) sum[i] = sum[i - 1] + a[i];

long long rangeSum = sum[r] - sum[l - 1];
```
性质：
- 可用于区间和。
- 可扩展到异或前缀。
- 不能直接解决任意区间最大值。
##### 环形前缀和
```cpp
for (int i = 0; i < n; i++) sum[i + 1] = sum[i] + dist[i];
for (int i = n; i < 2 * n; i++) sum[i + 1] = sum[i] + dist[i - n];
```
##### 差分
```cpp
vector<long long> d(n + 2, 0);
d[l] += x;
d[r + 1] -= x;

for (int i = 1; i <= n; i++) a[i] = a[i - 1] + d[i];
```

#### 9. 常见思想
##### 区间合并
- 先按左端点排序。
- 当前区间和上一个有交就合并。
##### 中位数 / 加权中位数
- 普通中位数常用于绝对值距离最小化。
- 加权绝对距离最小值常出现在加权中位数。
##### 贪心
- 先找局部最优选择是否可以推出全局最优。
- 常见于排序后处理、区间选择、贡献统计。
##### 高斯消元
- 适合线性方程组。
- 核心过程：选主元、消元、回代。
#### 10. 易错点
##### 输入输出
- `cin >> s` 读不到空格。
- `getline` 前面如果有 `cin >>`，要处理残留换行。
- 多组数据别忘记初始化。
##### 类型
- `1e9 * 1e9` 一定爆 `int`。
- 乘法、前缀和、答案统计优先考虑 `long long`。
##### 容器
- `queue` 没有 `top()`。
- `stack` 没有 `front()`。
- `priority_queue` 默认大根堆。
- `vector::erase()` 删除中间元素代价高。
##### 下标
- 统一使用 `0` 下标或 `1` 下标，不要混写。
- 图和树通常更适合 `1` 下标。
##### 二分
- 先想清楚查的是第一个满足条件的位置还是最后一个满足条件的位置。
- `mid` 推荐写成：
```cpp
int mid = l + (r - l) / 2;
```
